## 已做优化

- 首页改为加载 `data/review_items.json`，后续加科目时页面不会无限变重。
- 搜索支持“当前科目 / 全部科目”，并提供清空按钮和结果反馈。
- 清理 Word 转换带来的常见中文中间空格。
- 抽取报告会标记方剂缺少功用/主治、针灸同名分段等待核对内容。
